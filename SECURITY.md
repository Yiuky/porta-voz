# Política de segurança

## Versões com suporte

Correções de segurança são feitas na versão mais recente publicada em
[Releases](https://github.com/Yiuky/porta-voz/releases/latest).

## Como relatar uma vulnerabilidade

**Não abra uma issue pública** para falhas de segurança. Use o recurso
[*Report a vulnerability*](https://github.com/Yiuky/porta-voz/security/advisories/new) do GitHub (aba **Security** do
repositório), que cria um relato privado.

Inclua, se possível: versão do app, modelo do aparelho e versão do Android, passos para reproduzir e o impacto
esperado. Não anexe chaves de API nem gravações de ligações reais.

## Observações

- O app não usa servidor do autor: a chave de IA é da própria pessoa e as ligações são feitas pelo celular dela.
  Veja [PRIVACIDADE.md](PRIVACIDADE.md).
- Confira o SHA-256 dos APKs antes de instalar (valores no README).
